# Instruction (what the model must do)

This is the rules we give the model to follow. It sets role, tone, constraints, output format.

- The instruction is like the brief we give the model: who it is and exactly how it should answer.

## Context (what the model is allowed to use)

This is the data we give the model to use, e.g. documents, policies, facts. Context is the information we feed in.

## Query (what the user is asking)

This is the question we ask the model. It's the actual user question or task.

---

When we separate instruction, context, and query, the model knows what is rules, what is data, and what is the question — so we get more consistent, controllable answers.
